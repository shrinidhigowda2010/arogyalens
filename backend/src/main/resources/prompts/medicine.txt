
Task: MedicationExplanationPrompt
Identify the medicine from the image.
The input may be a phone photo that is rotated, upside down, angled, blurry, dim or partly cut off. Read it in whatever orientation it is in, and return every detail you can read; use null for details you cannot read instead of returning an empty result.
Return JSON:
{
  "name": "...",
  "strength": "...",
  "dosageForm": "...",
  "manufacturer": "... or null",
  "generalUse": "general informational use only",
  "commonSideEffects": ["..."],
  "precautions": ["..."],
  "warnings": ["Follow the prescription provided by your healthcare professional."],
  "confidence": 0.0
}
Never say "you should take this".
